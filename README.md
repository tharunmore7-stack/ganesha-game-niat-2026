# 🐘 Ganesha Game – NIAT 2026

An interactive and festive web game inspired by Lord Ganesha and created for the NIAT Game Design Contest 2026.

## 🎮 About the Game

This is a browser-based interactive game featuring:

* 🐘 Ganesha-themed visuals
* 🎮 Interactive gameplay
* 🎵 Background music and sound effects
* ✨ Festive animations
* 🏆 Score/progress system
* 👤 Player name and NIAT ID entry
* 📱 Responsive design for different screen sizes

## 🚀 Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## ▶️ How to Play

1. Open the game website.
2. Enter your Name.
3. Enter your NIAT ID.
4. Click **Get Started**.
5. Follow the instructions displayed in the game.
6. Complete the challenges and enjoy the game.
